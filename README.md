# Workspace Management User, Workspace, and Item classes code

## What you might need to run

### install node node -v npm -v
### npm install 
### npm install typescript 
### npm install (for dependencies)

## How to run the tester

Run from the **src** folder (not the entities folder):

```
cd src
npx tsx testers.ts
```

If `.env.local` is in a different location, update the path in `supabaseClient.ts` to point to it.
